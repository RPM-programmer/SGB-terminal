### SGB-terminal

### ***SGB-terminal*** - ресурс для создания банковского терминала. Для полной работы на свой сервер надо установить npm модуль — ***sequelize-game-bank***

Проект реализует клиент-серверную экосистему банковского IoT-терминала на базе микроконтроллера **Arduino Nano (или Uno)**, бесконтактного модуля **NFC PN532**, дисплея LCD 16x2 и Wi-Fi модуля **ESP-01 (ESP8266)**.

### Старт

1. **Перейдите в корень проекта (SGB-terminal) в терминале**
2. **Введите в командную строку:** 

```bash

node build.js
```
3. **Скрипт автоматически определит локальный IPv4 вашего ПК и попросит ввести данные локальной сети (имя Wi-Fi и пароль от него)**
4. **После ввода данных файл main.cpp.txt будет полностью настроен (значения подставятся вместо тегов-маркеров)**
5. **Скопируйте полученный код из main.cpp.txt и перенесите в ваш проект PlatformIO / Arduino IDE для прошивки контроллера**
6. **После этого запустите прокси-сервер командой:** 

```bash

node proxy/proxy.js
```

7. **В терминале появится зона для ввода ссылки реального сервера бэкенда; введите полную ссылку (URL) и нажмите Enter**

#### Важно! Запускать build.js нужно только при первой настройке или при смене Wi-Fi сети!

### 🔌 Спецификация аппаратного подключения

Чтобы избежать зависаний и ошибок «Not Found», периферия подключается по следующей схеме: 

### 1. Дисплей LCD 16x2 & NFC PN532 (Шина I2C)

Устройства подключаются параллельно к аппаратной шине I2C контроллера Arduino. 

* **SDA** ➡️ Аналоговый пин **A4**
* **SCL** ➡️ Аналоговый пин **A5**
* *Важно:* Переключатели на плате PN532 должны стоять в режиме I2C (SET 0: ON, SET 1: OFF).

### 2. Wi-Fi модуль ESP-01 (Шина UART / SoftwareSerial)

Для стабильной связи модуль **обязательно** должен подключаться через специальный **5V-to-3.3V адаптер питания (с чипом AMS1117)**, запитанный от мощного пина **5V** Arduino. Это защитит линии данных и обеспечит пиковый ток до 300 мА. 

* **TX (ESP-01)** ➡️ Цифровой пин **D10 (RX)** Arduino Nano
* **RX (ESP-01)** ➡️ Цифровой пин **D11 (TX)** Arduino Nano

#### Схема защиты линии RX (если адаптер не используется, сборка делителя из трех резисторов по 1 кОм):

```text

  Пин 11 (Arduino) ───[ Резистор 1 кОм ]───┬─── Пин RX (ESP-01)
                                           │
                                     [ Резистор 1 кОм ]
                                           │
                                     [ Резистор 1 кОм ]
                                           │
  Общая земля GND ─────────────────────────┴───────────────────
```

### 3. Клавиатура и индикаторы

* **Keypad 4x4:** Строки (Rows) ➡️ 9, 8, 7, 6, Столбцы (Cols) ➡️ 5, 4, 3, 2.
* **Светодиоды:** Зеленый (Успех) ➡️ пин **A0**, Красный (Ошибка) ➡️ пин **A1**.
* **Кнопка аварийного сброса:** Физическая кнопка Cancel ➡️ пин **D12** (INPUT_PULLUP).

### 🛠 Доступные API Роуты (Эндпоинты)

Взаимодействие терминала с прокси-сервером (порт 8080) происходит через POST-запросы с JSON-нагрузкой, после чего шлюз перенаправляет их на ваш боковой сервер ***sequelize-game-bank***: 

### 1. Регистрация и привязка новой карты

* **Путь:** ***/api/terminal/register***
* **Полезная нагрузка (JSON):** 

```json

{
  "id": "1234567890123456",
  "pincode": "5555",
  "card": "AABBCCDD"
}
```

### 2. Оформление денежного перевода

* **Путь:** ***/api/terminal/transfer***
* **Полезная нагрузка (JSON):** 

```json

{
  "card": "AABBCCDD",
  "to": "9876543210987654",
  "pincode": "5555",
  "manny": "1500"
}
```
